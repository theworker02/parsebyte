# parsebyte

Parse identifiers and byte tokens for idempotent workflows.

**Site:** https://theworker02.github.io/parsebyte/

## Install / run

```bash
git clone https://github.com/theworker02/parsebyte.git
cd parsebyte
node src/cli.js
node --test
```
